# Variation engine

The reason builds look the same is that only the *materials* change while the skeleton stays
identical. Fix the skeleton, not the skin.

## Contents

- How to use
- Dimension tables
- Settlement rules
- Session memory
- Checks

## How to use

Before building, pick one value per dimension below - deliberately, or by rolling a d6 - and
**state the combination in the answer**, e.g.:

> Rolled: L-footprint, 2 masses + porch, gambrel + shed dormers, 2 floors with jetty,
> base = tuff bricks blend, accent = copper, motif = exposed timber braces.

Then build to that combination. Half the dimensions must differ from the previous build in
the same session.

## Dimension tables

**1. Footprint** - rectangle+satellite / L / T / U / cross / stepped-terraced

**2. Mass count** - 1 mass + porch / 2 masses / 2 masses + tower / 3 masses / core + 3
satellites / cluster of 4+

**3. Floors and section** - 1 / 1 + attic / 2 / 2 + jetty on upper floor / 2.5 with dormers /
3 stepped back

**4. Roof type** - see `roofs.md`; never the same type twice in a row on the primary mass

**5. Roof pitch** - 45 / shallow 1:2 / steep 2:1 / compound steep-then-shallow / bell-cast
flare / mixed per mass

**6. Entrance** - recessed 1-2 / projecting porch with own roof / arched / corner entry /
courtyard gate / stair up to a raised door

**7. Openings rhythm** - even bays / A-B-A / grouped pairs / one large + several small /
asymmetric cluster / vertical strip windows

**8. Base material family** - stone bricks blend / deepslate blend / tuff blend (1.21+) /
cobble+andesite / mud brick + plaster / wood-dominant

**9. Accent** - copper (any oxidation) / dark wood trim / warm plaster / prismarine or
blue-glazed / red brick or nether brick / calcite white

**10. Signature motif** - exposed timber braces / arcade of arches / oriel window / external
stair or gallery / chimney stack cluster / green roof or planters / balcony rings / carved
gable

**11. Terrain response** - flat with plinth / stepped down a slope / cut into hill / on stilts
over water / terraced platform / built around a rock or tree

**12. Wear and age** - new and crisp / lived-in (moss at base) / weathered (cracks, patina) /
half-ruined wing / recently extended (two visibly different eras)

## Settlement rules

When building more than one structure:

- Shared: base material family, road material, roof material family, window language. This is
  what makes the settlement coherent.
- Varied per building: footprint, mass count, height, roof type, accent, motif, orientation.
- No two neighbours share roof type + footprint at once.
- Vary total height by +/-25% and footprint area by +/-40% across the settlement.
- 1 in 5 buildings gets an "exception": bigger, older, richer, or a different function.
- Rotate buildings so they face streets and squares, not all the same way; a few off-axis
  buildings make the settlement feel grown.

## Session memory

Keep a short list in the answer thread of what was already used (roof types, footprints,
accents). Before a new build, re-read it and pick unused values. If the user liked a specific
build, vary the *other* dimensions and keep the ones they praised.

## Checks

- [ ] Combination stated explicitly.
- [ ] At least 6 of 12 dimensions differ from the previous build.
- [ ] Roof type not repeated back-to-back.
- [ ] Silhouette differs, not just the palette.
- [ ] In settlements, no two neighbours share roof + footprint + accent.
