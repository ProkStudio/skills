# Ready-made tier palettes

Each palette is base (~60%) / secondary (~30%) / accent (~10%) / trim / light. Version gates
are marked; fallbacks are given where a palette leans on a gated family.

## Stone-and-timber

**1. Medieval village**
base stone bricks + cracked + mossy stone bricks; secondary spruce log / stripped spruce;
accent deepslate tile stairs (roof); trim polished andesite, cobblestone wall; light lantern,
campfire.

**2. Nordic dark**
base cobbled deepslate + deepslate bricks; secondary dark oak log, dark oak planks; accent
spruce stairs roof + hay; trim polished deepslate slab; light soul lantern, campfire.

**3. Warm cottage**
base white terracotta + calcite; secondary oak log, stripped oak; accent bricks (chimney),
dark oak stairs (roof); trim smooth stone, oak fence; light lantern, candles.

**4. Tuff keep (1.21+)**
base tuff bricks + polished tuff + chiseled tuff; secondary dark oak; accent oxidized cut
copper stairs; trim tuff wall, polished tuff slab; light copper bulb, lantern.
Fallback before 1.21: deepslate bricks + polished deepslate + stone bricks.

## Stone-and-plaster

**5. Tudor / half-timbered**
base white terracotta + bone block (infill); secondary dark oak log frame; accent deepslate
tiles roof; trim cobblestone base course, spruce trapdoor shutters; light lantern.

**6. Mediterranean**
base smooth sandstone + sandstone + calcite; secondary spruce beams; accent bricks or resin
bricks (1.21.4) roof; trim sandstone wall, smooth sandstone stairs; light lantern, candles.

**7. Desert adobe**
base packed mud + mud bricks + smooth sandstone; secondary acacia log; accent orange terracotta;
trim mud brick wall, exposed log beams; light lantern, campfire.

## Modern

**8. Modern minimal warm**
base white concrete + smooth quartz; secondary birch planks or bamboo planks (1.20+); accent
black concrete lines; trim smooth stone slab, iron bars; light glowstone behind trapdoors,
end rod.

**9. Modern brutalist**
base light gray concrete + smooth stone + andesite; secondary dark oak; accent black concrete;
trim polished andesite; light sea lantern hidden in coffers.

**10. Glass-and-steel**
base tinted glass + black concrete frame; secondary polished deepslate; accent white concrete
bands; trim iron bars, chains; light end rod, sea lantern.

## Dark and dramatic

**11. Gothic cathedral**
base deepslate bricks + cracked deepslate bricks + polished deepslate; secondary blackstone;
accent stained glass (purple/blue/red) + gold block filigree; trim deepslate tile wall,
chiseled deepslate; light soul lantern, candles, glowstone behind glass.

**12. Dwarven forge**
base blackstone + polished blackstone bricks + basalt; secondary dark oak, iron blocks;
accent gold block, copper; trim chiseled polished blackstone, chains; light lava, magma,
shroomlight, lantern.

**13. Nether outpost**
base red nether bricks + nether bricks + blackstone; secondary crimson stems; accent gilded
blackstone; trim nether brick fence, chains; light soul lantern, shroomlight, campfire.

## Light and soft

**14. Cherry spring (1.20+)**
base calcite + white terracotta; secondary cherry planks + cherry log; accent pink petals,
pink terracotta; trim smooth quartz slab, cherry fence; light lantern, candles.

**15. Pale garden (1.21.4+)**
base pale oak planks + white terracotta; secondary pale oak log, calcite; accent pale moss
carpet, resin bricks; trim pale oak fence, polished diorite; light soul lantern, candles.
Fallback: birch + white terracotta + moss carpet.

**16. Elven / high fantasy**
base smooth quartz + calcite + bone block; secondary birch or pale oak (1.21.4+); accent
oxidized copper + prismarine details; trim quartz stairs, chains; light sea lantern, end rod,
amethyst.

## Industrial and technical

**17. Steampunk industrial**
base bricks + deepslate bricks; secondary dark oak, iron blocks, copper block gradient; accent
copper grate + copper bulb (1.21+); trim iron bars, chains, anvils; light copper bulb, lantern,
campfire smoke.
Fallback before 1.21: cut copper, iron trapdoors, redstone lamps.

**18. Sci-fi clean**
base white concrete + smooth quartz + light gray concrete; secondary iron blocks; accent
blue/cyan stained glass, prismarine; trim iron bars, end rods; light sea lantern, end rod,
tinted glass over glowstone.

## How to adapt any palette

1. Swap the accent first - it changes the personality with 10% of the blocks.
2. To make a palette colder: replace warm whites with cool whites and wood with stone.
3. To age it: add mossy/cracked siblings at the base, swap 10% of the base for the noisy
   variant, and add glow lichen and vines on shaded faces.
4. To modernise it: cut to 2 blocks per tier, remove noisy variants, sharpen trim lines.
5. Keep one wood family and one stone family unless the contrast is structural.
